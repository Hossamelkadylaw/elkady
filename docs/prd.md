# وثيقة المتطلبات

## 1. نظرة عامة على التطبيق
تطبيق جوال مخصص لإدارة أعمال مكتب المستشار أحمد كامل للمحاماة، يهدف إلى تمكين إدارة ومتابعة القضايا، الجلسات، بيانات العملاء، والمستندات المرتبطة عبر الهواتف الذكية بنظام أندرويد، استناداً إلى النظام المرجعي المتوفر في الملف lawyer_office_system_standalone.zip.

## 2. المستخدمون وحالات الاستخدام
- **المستخدم المستهدف**: المحامون والإداريون في مكتب المستشار أحمد كامل للمحاماة.
- **حالات الاستخدام الرئيسية**:
  - تسجيل الدخول والوصول السريع إلى ملخص الأعمال اليومية.
  - متابعة وإدارة القضايا والاطلاع على تفاصيلها ومستنداتها.
  - جدول ومتابعة جلسات المحاكم القادمة والسابقة.
  - إدارة سجلات وبيانات التواصل مع العملاء.

## 3. هيكل الشاشات وتوصيف الوظائف

### 3.1 هيكل التطبيق الشجري
- شاشات المصادقة
  - تسجيل الدخول
  - إنشاء حساب جديد
- شاشة الرئيسية (لوحة المعلومات)
- إدارة القضايا
  - قائمة القضايا
  - شاشة تفاصيل القضية والمستندات
- إدارة الجلسات
  - قائمة الجلسات ومواعيدها
- إدارة العملاء
  - قائمة العملاء وبياناتهم

### 3.2 توصيف وظائف الشاشات

#### 3.2.1 المصادقة والتسجيل
- **تسجيل الدخول**: إدخال رقم الهاتف واستلام رمز التحقق لإنشاء جلسة عمل داخل التطبيق.
- **إنشاء حساب**: إدخال الاسم، رقم الهاتف، والتحقق عبر الرمز لإنشاء مستخدم جديد للنظام.

#### 3.2.2 شاشة الرئيسية
- عرض ملخص وإحصائيات عامة تشمل عدد القضايا النشطة، جلسات اليوم، وأحدث العملاء المضافين.
- شريط تنقل سفلي يتيح الانتقال بين الأقسام الرئيسية (الرئيسية، القضايا، الجلسات، العملاء).

#### 3.2.3 شاشة القضايا وتفاصيلها
- **قائمة القضايا**: استعراض القضايا المسجلة مع رقم القضية، اسم العميل، المحكمة، والحالة.
- **تفاصيل القضية**: استعراض معلومات القضية الكاملة، الجلسات المرتبطة بها، وسجل المستندات المرفقة الخاصة بالقضية.

#### 3.2.4 شاشة الجلسات
- عرض جدول زمني للجلسات مع تفاصيل المحكمة، الدائرة، تاريخ ووقت الجلسة، والقرار أو المطلوب في الجلسة.

#### 3.2.5 شاشة العملاء
- استعراض قائمة العملاء مع بيانات الاتصال (الهاتف، العنوان) وحصر القضايا المرتبطة بكل عميل.

## 4. القواعد والمنطق البرمجي
- اعتماد البيانات المرجعية والهيكل العام الموضح في ملف lawyer_office_system_standalone.zip لتنظيم حقول القضايا والجلسات والعملاء.
- ربط كل جلسة ومستند بالقضية والعميل التابع لهما لضمان اتساق البيانات.
- حفظ البيانات مركزيًا في الخادم لضمان تحديثها الفوري واستقبال التحديثات المستقبلية.

## 5. الحالات الاستثنائية والحدية
| الحالة الاستثنائية | الإجراء المتخذ |
| --- | --- |
| إدخال رقم هاتف غير صحيح عند الدخول | تنبيه المستخدم بضرورة إدخال رقم هاتف صحيح |
| عدم إدخال رمز التحقق بشكل مطابق | إظهار رسالة خطأ وإتاحة إعادة إرسال الرمز |
| عدم وجود جلسات في تاريخ محدد | إظهار شاشة توضح عدم وجود مواعيد جلسات مسجلة لهذا اليوم |
| فتح قضية بدون مستندات | عرض إشعار يفيد بعدم إرفاق مستندات بعد في هذه القضية |

## 6. معايير القبول والاعتماد
1. يقوم المستخدم بإدخال رقم الهاتف وتأكيد رمز التحقق لتسجيل الدخول إلى التطبيق.
2. يتم نقله إلى شاشة الرئيسية حيث تظهر الإحصائيات العامة للمكتب.
3. ينتقل المستخدم إلى شاشة القضايا، ويختار إحدى القضايا القائمة.
4. يدخل إلى شاشة تفاصيل القضية ويستعرض بياناتها والمستندات والجلسات التابعة لها بنجاح.

## 7. خارج نطاق العمل الحالي
- نظام سداد الأتعاب والمدفوعات الإلكترونية.
- الإشعارات الفورية التلقائية عبر الرسائل النصية خارج التطبيق.
- ميزة المحادثات المباشرة بين العميل والمحامي داخل التطبيق.
